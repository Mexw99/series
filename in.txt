บรรทัดนี้อนุญาตให้ APK เชื่อมต่ออินเทอร์เน็ตได้
    ถ้าไม่มี permission นี้:
    - ตอนรันบนเครื่องพัฒนาอาจดูเหมือนใช้งานได้
    - แต่ APK ที่ build แล้วอาจเรียก API ไม่ได้
    - คำคมและซีรีส์แนะนำจะโหลดไม่สำเร็จ
ต้องวางไว้เหนือ <application>:
<manifest>
    <uses-permission .../>
    <application>

12. android/gradle.properties
ไฟล์:
[gradle.properties](/Users/bootsabong/Documents/GitHub/series/series/android/gradle.properties)
เพิ่ม locale:
-Duser.language=en
-Duser.country=US
สาเหตุคือเครื่องใช้ locale ไทย ทำให้ Gradle อ่านปีเป็น พ.ศ. เช่น 2569
แต่ Android ZIP merger รองรับปี ค.ศ. ในช่วงประมาณ 1980–2107 จึงเกิด error:
VerifyException
การตั้งค่า locale นี้มีผลเฉพาะขั้นตอน build ไม่ได้เปลี่ยนภาษาในแอป


รันคำสั่งนี้ในโฟลเดอร์ Flutter ที่มี pubspec.yaml อยู่ เช่น series/series:
flutter pub add http
คำสั่งนี้จะเพิ่ม package http ใน pubspec.yaml และดาวน์โหลด dependency ให้อัตโนมัติ
ส่วน Internet permission ไม่มีคำสั่ง Flutter สำหรับเพิ่มให้อัตโนมัติ ต้องเปิด android/app/src/main/AndroidManifest.xml แล้วใส่บรรทัดนี้ไว้เหนือ <application>:
<uses-permission android:name="android.permission.INTERNET"/>
บันทึกไฟล์แล้ว build แอปใหม่ครับ.

ขั้น 2 เพิ่มการตั้งค่าใน pubspec.yaml (ท้ายไฟล์)

flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/icon.png"      # ที่อยู่รูปไอคอน
ขั้น 3 เพิ่ม assets ใน pubspec.yaml (ใต้ flutter:) ถ้ามี flutter: อยู่แล้วให้เพิ่ม assets เข้าไปไม่ต้องเพิ่มใหม่

flutter:
  assets:
    - assets/icon.png
